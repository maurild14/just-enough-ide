# JEI v0.4 cleanup, review and file operations implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task by task. Steps use checkbox syntax; git history and the ignored execution ledger record completion.

**Goal:** Remove Symbols completely, make replacement case-sensitive, reconcile current documentation, review the unreviewed v0.3 tail, and deliver safe Files operations on both hosts.

**Architecture:** Preserve the pure TypeScript core and both thin native adapters. Search remains literal and case-insensitive; replacement filters each verified match by exact text. A new pure `core/fsops.ts` validates requests against lexical and canonical project boundaries and builds OS-specific argv; Claude executes through its installed APIs, while OpenCode executes filesystem mutations on the server.

**Tech stack:** TypeScript, Bun tests, Claude Code plugin testing kit, installed Claude Code declarations, OpenCode 2.0.32 RPC, Solid/OpenTUI and Node filesystem APIs. No new runtime dependencies.

**Scope boundary:** This is the first part of v0.4: cleanup, review and file operations. Polish, launch, GIFs, announcements, publication, tags, and GitHub/npm configuration changes are deferred. Work on the existing clean `main`; only the controller pushes `origin main` after each approved task.
